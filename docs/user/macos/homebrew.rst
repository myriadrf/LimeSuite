Homebrew
########

The Pothosware Homebrew tap has a build recipe for Lime Suite. 

To install LimeSuite:

1. Install the `Xcode Command Line Tools`_
2. Install `Homebrew`_
3. Run the following commands:

.. code-block:: bash

   brew tap pothosware/homebrew-pothos
   brew update
   brew install limesuite

Also check out the `dholm Homebrew tap`_ for other SDR related software.

.. _Xcode Command Line Tools: https://railsapps.github.io/xcode-command-line-tools.html
.. _Homebrew: https://brew.sh/
.. _dholm Homebrew tap: https://github.com/dholm/homebrew-sdr
