USB Driver
##########

Download the `LimeSDR USB driver`_ and unzip the package. 

The LimeSDR should appear as an unrecognised device in the device manager. Use the device properties dialogue to specify the path to the LimeSDR USB drivers directory. Once the proper directory is specified, the driver installation should complete successfully. 

.. figure:: /images/Limesdr_windows_driver_install.png
   :align: center

.. _LimeSDR USB driver: https://github.com/myriadrf/Windows-drivers/archive/master.zip
