Windows
#######

.. toctree::
   :maxdepth: 1
   :hidden:

Lime Suite can be installed on Windows via applications which bundle it, or by building it from source code.

When installing via source code you will need to install the USB driver. This may also be required when installing via a bundled application, depending on the application and how it bundles Lime Suite.
